# 🎵 Spotify Daylist Exporter

> Быстрый веб-инструмент для сохранения исчезающего Spotify Daylist в `.txt` и мгновенного добавления треков в свой Spotify всего одной кнопкой (через буфер обмена `Cmd+V` / `Ctrl+V`).

🔗 **Сайт (GitHub Pages):** [https://slawastr.github.io/spotify-daylist-exporter/](https://slawastr.github.io/spotify-daylist-exporter/)

---

## ⚡️ В чём фишка Daylist?

Spotify Daylist меняется несколько раз в день (утром, днём, вечером, ночью). Если вам понравился текущий микс, через пару часов он исчезнет навсегда. 

**Spotify Daylist Exporter** решает эту проблему:
1. Вы просто вставляете ссылку на свой Daylist (например `https://open.spotify.com/playlist/37i9dQZF1FbEn59rE9ZAPD?si=...`).
2. Получаете полный список треков с обложкой, названиями, исполнителями и предпрослушиванием.
3. Скачиваете список в `.txt` файл для архива.
4. Нажимаете кнопку **«Скопировать для Spotify»** и добавляете все 50 треков в свой плейлист за 1 секунду!

---

## 🚀 Как добавить треки в свой Spotify (Магия Cmd+V)

В официальном десктопном приложении Spotify на Mac и Windows есть встроенная функция пакетной вставки треков:

1. Откройте **Spotify Daylist Exporter** и нажмите зелёную кнопку **«Скопировать для Spotify (Cmd+V)»**.
2. Откройте приложение **Spotify** на компьютере (Mac или Windows).
3. Создайте новый плейлист (или откройте существующий) и кликните в область треков.
4. Нажмите **`Cmd + V`** (на macOS) или **`Ctrl + V`** (на Windows).
5. **Все 50 треков моментально добавятся в ваш плейлист!** 🎉

## 📁 Восстановление из .txt файла (Вкладка «Импорт»)

Если вы сохранили Daylist в `.txt` файл месяц назад и хотите снова собрать этот плейлист в Spotify:
1. Перейдите во вкладку **«Импорт / Добавить из .txt»**.
2. Перетащите ваш `.txt` файл (или вставьте строки текста).
3. Нажмите **«Скопировать для Spotify»**.
4. Вставьте в приложении Spotify через `Cmd+V` / `Ctrl+V`.

## 🛠 Возможности

- 🔗 **Поддержка любых ссылок Spotify**: Daylist, обычные плейлисты, ссылки с `?si=...`, URI вида `spotify:playlist:...`.
- 💾 **Гибкий экспорт в .txt**:
  - `Исполнитель — Название`
  - Нумерованный список `1. Исполнитель — Название`
  - Spotify URIs (`spotify:track:...`)
  - Spotify Web Links (`https://open.spotify.com/track/...`)
  - Подробный с таймингами
- 🎧 **Встроенный аудио-плеер**: 30-секундное демо каждого трека прямо на странице.
- 🔍 **Поиск и фильтрация**: живой поиск по трекам и артистам, выбор отдельных треков галочками.
- 🔒 **100% приватность**: весь парсинг и генерация происходят на клиенте в браузере, без хранения ваших личных данных.
- 📱 **Адаптивный дизайн**: идеально работает на смартфонах, планшетах и компьютерах в темной теме Spotify.

## 💻 Локальный запуск

Приложение не требует Node.js, сборщиков или бэкенда — это чистый HTML/CSS/JS:

```bash
git clone https://github.com/SLAWASTR/spotify-daylist-exporter.git
cd spotify-daylist-exporter
open index.html
```
